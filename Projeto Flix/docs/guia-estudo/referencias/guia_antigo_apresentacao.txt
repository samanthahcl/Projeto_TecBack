3. Fluxo geral de uma requisicao
Quando voce clica em Execute no Swagger, acontece um fluxo parecido com este:
1. O usuario acessa um endpoint, por exemplo POST /api/v1/usuarios.
2. O Controller recebe o JSON da requisicao.
3. O DTO valida os campos com anotacoes como @NotBlank, @Email, @SenhaForte e @CpfCnpj.
4. O Controller chama o Service.
5. O Service aplica a regra de negocio. Por exemplo: verifica se o e-mail ja existe e faz hash da senha.
6. O Repository salva ou busca dados no banco H2.
7. O Service transforma a Entity em DTO de resposta.
8. A API devolve JSON para o Swagger.
Swagger -> Controller -> DTO/Validation -> Service -> Repository -> Banco H2
Banco H2 -> Repository -> Service -> DTO -> Controller -> Swagger

5. RF3 - Senha com hash BCrypt
O RF3 exige que a senha nao fique salva em texto puro. No seu projeto, isso esta no UsuarioService.
usuario.setSenhaHash(passwordEncoder.encode(dto.getSenha()));
O metodo encode transforma a senha digitada em um hash BCrypt. Por exemplo, se a senha digitada for 
Senha123@, o banco nao guarda esse texto. Ele guarda uma sequencia criptografada iniciada geralmente 
por $2a$ ou $2b$.
Como explicar ao professor: No cadastro, a senha do DTO nunca e salva diretamente. O service usa 
BCryptPasswordEncoder para gerar um hash e salva esse resultado no campo senhaHash da entidade Usuario.
O UsuarioService tambem evita duplicidade de e-mail:
if (usuarioRepository.existsByEmail(dto.getEmail())) {
    throw new ResponseStatusException(HttpStatus.CONFLICT, "E-mail já cadastrado");
}
Isso evita duas contas com o mesmo e-mail.

13. Tratamento de erros
O tratamento de erros fica em GlobalExceptionHandler. A ideia e padronizar as respostas de erro da API.
Exemplo: se um campo obrigatorio vier vazio, em vez de aparecer um erro tecnico enorme do Java, a API 
retorna um JSON mais claro, com status, mensagem e caminho da requisicao.
Esse ponto e importante porque o professor citou handlers de excecao como parte da avaliacao.
Erros comuns que seu sistema trata
 Erro de validacao de campos, como nome vazio ou e-mail invalido.
 Erro de recurso nao encontrado, como usuario inexistente ou conteudo inexistente.
 Erro de conflito, como e-mail ja cadastrado ou favorito duplicado.
 Erro interno generico, quando algo inesperado acontece.
Boa pratica: Nao deixar stacktrace exposto ao usuario. Seu application.properties configura server.error.include-
stacktrace=never, o que evita mostrar detalhes tecnicos demais no retorno da API.
14. H2, JPA e persistencia
Persistencia significa salvar dados no banco. No projeto, a persistencia foi feita com Spring Data JPA, 
Hibernate e H2.
H2

Repository
Quando uma interface estende JpaRepository, ela ganha metodos prontos como save, findById, findAll, 
deleteById e existsById.
public interface UsuarioRepository extends JpaRepository<Usuario, Long> {
    boolean existsByEmail(String email);
    Optional<Usuario> findByEmail(String email);
}

18. Perguntas que o professor pode fazer
Por que voce usou DTO?
Resposta: Usei DTO para separar os dados da API das entidades do banco. Assim eu controlo o que entra 
e sai, aplico validacoes e evito expor campos sensiveis, como senhaHash.
Onde a senha e criptografada?
Resposta: No UsuarioService, no metodo criar, com passwordEncoder.encode(dto.getSenha()). O valor e 
salvo em senhaHash.
Como o login funciona?
Resposta: O AuthService busca o usuario pelo e-mail, depois usa passwordEncoder.matches para 
comparar a senha digitada com o hash salvo no banco. Se estiver correto, retorna LoginResponseDTO.
Como voce separa filmes e series nos favoritos?
Resposta: O FavoritoRepository faz um JOIN entre Favorito e Conteudo e filtra pelo campo tipo, usando 
FILME ou SERIE.
Como o admin e exigido?
Resposta: No SecurityConfig, os endpoints POST, PUT e DELETE de /api/v1/conteudos exigem 
hasRole("ADMIN"). O usuario admin e criado em memoria com admin/admin123.
O que e JPQL?
Resposta: JPQL e uma linguagem de consulta orientada a entidades Java. Em vez de consultar tabelas 
diretamente, consulto a entidade Conteudo.
O que o Swagger faz?
Resposta: O Swagger gera a documentacao interativa da API e permite testar os endpoints diretamente no 
navegador.
Qual banco voce usou?
Resposta: Usei H2 em arquivo para desenvolvimento, com Spring Data JPA e Hibernate para persistencia.
